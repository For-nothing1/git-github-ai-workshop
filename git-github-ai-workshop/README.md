# Git & GitHub with AI — Hands-on Workshop 🚀

A beginner-friendly practical workshop for Git, GitHub and AI-assisted development.

## Learning path

**Understand → Practice Git → Use GitHub → Collaborate → Use AI → Review AI output**

Read the `docs/` files if you are new to Git.

Then complete the labs in order:

```text
Lab 00 Setup
Lab 01 First Commit
Lab 02 Clone / Push / Pull
Lab 03 Branching
Lab 04 Pull Request
Lab 05 Merge Conflict
Lab 06 Issues
Lab 07 AI Coding
Lab 08 AI Code Review
Lab 09 Final Challenge
```

## Golden workflow

```text
EDIT → STATUS → ADD → COMMIT → PUSH
```

Team workflow:

```text
ISSUE → BRANCH → CODE → COMMIT → PUSH → PULL REQUEST → REVIEW → MERGE
```

## Setup

```bash
git --version
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
git clone https://github.com/YOUR-USERNAME/git-github-ai-workshop.git
cd git-github-ai-workshop
```

**Important:** AI-generated code must be read, understood, tested and reviewed before committing.
