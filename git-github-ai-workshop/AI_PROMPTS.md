# AI Prompt Sheet

## Understand
Explain this code as if I am a beginner. Use a small example.

## Debug
Find the bug. Explain the cause before suggesting a fix.

## Improve
Suggest three improvements without changing the code yet. Explain why.

## Testing
Generate normal, edge-case and invalid-input tests.

## Documentation
Create a beginner-friendly README with setup and usage.

## Code review
Review this code for correctness, security, readability, maintainability and testing.

## Git help
I am a Git beginner. Explain this error, why it happened, and the safest next command.

## Agent planning
Analyze this repository and propose a plan to implement this task. Do not modify anything until the plan is clear.

**Rule: ASK → READ → UNDERSTAND → TEST → REVIEW → COMMIT**
