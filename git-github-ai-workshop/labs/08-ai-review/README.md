# Lab 08 — AI Code Review

Create a Pull Request containing a small code change.

If AI code review is available, request a review.

Prompt:

> Review this code like a senior developer. Find correctness issues, security concerns, edge cases, maintainability problems and missing tests. Prioritize issues by severity.

For every suggestion:
1. Read it.
2. Decide if it is correct.
3. Test the fix.
4. Commit only verified changes.
