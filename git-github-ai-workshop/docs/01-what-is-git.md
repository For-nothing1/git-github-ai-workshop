# What is Git?

**Git is a version control system.**

It records changes in your project so you can see what changed, create checkpoints, work on features safely, and collaborate.

### Think of Git as a time machine

Instead of:

```text
final.zip
final-new.zip
final-final.zip
really-final.zip
```

you create meaningful checkpoints called **commits**.

### Important terms

| Term | Simple meaning |
|---|---|
| Repository | A project tracked by Git |
| Working directory | Files you are editing |
| Staging area | Changes selected for the next commit |
| Commit | A saved checkpoint |
| Branch | Separate line of development |
| Remote | Another copy of the repository |
| Push | Send commits to a remote |
| Pull | Bring remote changes to your computer |

Git can perform many operations locally without internet access.

**Memory trick: Git = Time Machine.**
