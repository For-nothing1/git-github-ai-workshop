# What is GitHub?

**GitHub is an online platform for hosting Git repositories and collaborating on software.**

Git and GitHub are different:

```text
Git      = version control system
GitHub   = online collaboration platform
```

GitHub provides repositories, Issues, Pull Requests, code review, Actions, project management and AI-assisted development features.

### Basic connection

```text
Your computer
     |
  git push
     v
   GitHub
     |
  git pull
     v
Your computer
```

### Typical GitHub workflow

```text
Issue → Branch → Code → Commit → Push → Pull Request → Review → Merge
```

**Memory trick: Git is the engine; GitHub is the online collaboration center.**
