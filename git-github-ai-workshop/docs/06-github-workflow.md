# Professional GitHub Workflow

A common workflow is:

```text
Issue
 ↓
Branch
 ↓
Code
 ↓
Commit
 ↓
Push
 ↓
Pull Request
 ↓
Code Review
 ↓
Tests
 ↓
Merge
```

### Issue
Describes work that needs to be done.

### Branch
Lets you develop without directly changing `main`.

### Pull Request
Requests review and merging of your changes.

### Review
Checks correctness, readability, security, tests and maintainability.

This is the workflow you will practice in the labs.
