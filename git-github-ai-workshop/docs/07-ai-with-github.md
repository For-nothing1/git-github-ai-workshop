# GitHub + AI

AI can assist with many development tasks.

### Understand
> Explain this code as if I am a beginner.

### Debug
> Find the bug and explain the cause before suggesting a fix.

### Test
> Generate normal, edge-case and invalid-input tests.

### Document
> Create a beginner-friendly README for this project.

### Review
> Review this code for correctness, security, maintainability and missing tests.

### Agent-style task
> Analyze the repository and propose a plan to add input validation. Do not modify anything until the plan is clear.

### Golden AI rule

**ASK → READ → UNDERSTAND → TEST → REVIEW → COMMIT**

AI can make mistakes. The developer remains responsible for the final code.
